# ApexDiagram issue tracker

This repository is the public bug tracker for [ApexDiagram](https://apexdiagram.com). It contains no source code; it exists only so you can report problems and track their status.

## How to report

- **Bug** – something is broken or behaves unexpectedly. Use the *Bug report* form.
- **Feature request** – something you wish ApexDiagram did. Use the *Feature request* form, or post and vote on the [community board](https://apexdiagram.com/community).
- **Security vulnerability** – do **not** open an issue. Email security@apexdiagram.com.

Before opening a new issue, search the existing ones. If you find a match, add a 👍 reaction or a comment rather than filing a duplicate.

## What to include

Steps to reproduce, what you expected, what actually happened, and your browser. Screenshots or a short recording help a lot. Please do not paste diagram exports, device inventories, credentials or anything else you would not want public: this tracker is visible to everyone.

## Status labels

| Label | Meaning |
| --- | --- |
| `triage` | New, not yet reviewed |
| `confirmed` | Reproduced by the team |
| `in progress` | Being worked on |
| `fixed` | Shipped to production |
| `needs info` | Waiting on the reporter |
| `wontfix` | Reviewed and declined, with a reason in the thread |
